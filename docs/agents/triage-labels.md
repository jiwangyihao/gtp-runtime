# Triage 标签

工程技能以五个 canonical role 推进 Issue 状态；本仓库直接使用同名 GitHub label。

| Canonical role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 AFK Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 明确不处理 |

技能提到 canonical role 时，必须使用右列对应的实际 GitHub label，避免创建语义重复的标签。
